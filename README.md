# C++ Programming Lab

This repository contains the programming assignments and source codes completed as part of our C++ coursework, covering practical implementations.

## Completed Programs (1–9)
1. **Palindrome Check:** Check number and string palindromes.
2. **Call by Value & Reference:** Demonstrate function argument passing.
3. **Matrix Operations:** Addition, subtraction, multiplication, and transpose using functions and switch case.
4. **Constructors & Destructors:** Shape class for perimeter calculation.
5. **Array of Objects & Inline Functions:** Person class and salary slip generation.
6. **Operator Overloading:** Unary (`++`, `--`) and binary (`+`, `-`) operations on complex numbers.
7. **Function Overloading:** Calculate areas of a circle, rectangle, and triangle.
8. **Inheritance:** `Student`, `Exam`, and `Result` class hierarchy.
9. **Friend Function:** Swap two numbers using two classes.
